# Phase 13 – JWT Authentication Configuration

## Objective
Configure JWT Bearer authentication for the Movie Ticket Booking API.

## Implementation
- Installed Microsoft.AspNetCore.Authentication.JwtBearer.
- Configured JWT issuer and audience.
- Configured signing key.
- Enabled token lifetime validation.
- Enabled signing-key validation.
- Configured authentication and authorization middleware.
- Stored development JWT settings using .NET User Secrets.

## Outcome
The API is configured to validate JWT Bearer tokens.

## Next Phase
User Registration with ASP.NET Core Identity.
